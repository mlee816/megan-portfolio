HyTech Racing

Steering System Firmware

I worked on the steering firmware for Georgia Tech's Formula SAE team. The system reads an analog potentiometer and a digital encoder at 500 Hz and turns those inputs into steering measurements for vehicle control.

  • Developed the C++ firmware interface, including bit masks, command constants, an error struct, and public functions for data sampling and sensor calibration.
  • Built a steering system layer on top of the interface, implementing a rolling buffer of readings, min/max tracking, timestamped data, steering angle conversions, and sensor arbitration logic with error flagging implemented based on velocity, sudden changes, out-of range values.
  • Implemented software calibration triggered through a CAN message chain: button press -> CAN message -> received by VCR FSM -> state validation -> calibration command sent back to VCF -> steering system recalibrates parameters.

Digital Design Lab

ADC Peripheral for the SCOMP Processor

I designed a memory-mapped ADC peripheral in VHDL so the SCOMP processor could read analog voltage levels. The hardware also handles threshold comparisons, rather than making the processor do that work in software.

I packed the 12-bit ADC reading and two threshold flags into one 16-bit register, accessible through the processor's IN/OUT instructions.
